🛠️ The Complete 5-Level RAP Toolkit

LEVEL 1 · PATH SANITIZER

⚠️ Audit Legacy Script Paths ➔

Convert hardcoded local machine paths to project-relative paths.

# ❌ Bad: Absolute Path
pd.read_csv("C:/Users/name/data.csv")

# ✅ Good: Relative Path
pd.read_csv("data/raw/survey.csv")
LEVEL 2 · ENVIRONMENT LOCK

🔒 pyproject.toml Lockfile ➔

Pin exact package versions for 100% execution reproducibility.

[project]
name = "survey-rap-pipeline"
version = "1.0.0"
dependencies = [
  "pandas==2.2.1",
  "statsmodels==0.14.1",
  "scikit-learn==1.4.1"
]
LEVEL 3 · PIPELINE DAG

⚡ Task Orchestration & Caching ➔

Define explicit task dependencies and reuse cached data steps.

from prefect import task, flow

@task(retries=2)
def clean(raw): return df.dropna()

@flow
def main(): clean("data/raw/s.csv")
LEVEL 4 · QUALITY ASSERTIONS

🛡️ Data Schema Testing ➔

Halt pipeline execution automatically if incoming data is bad.

def test_survey_data_quality():
  df = pd.read_csv("processed.csv")
  assert df["id"].notnull().all()
  assert df["risk"].between(1, 5).all()
